## 📖 About

**Movies & Shows** is a full-stack web application for browsing and exploring movies and TV series.

The project combines a responsive frontend built with **HTML, CSS, and JavaScript** with a powerful **Django backend** for handling application logic, data, and dynamic content.

---

## ✨ Features

- 🎬 Browse movies
- 📺 Browse TV shows
- 🔎 Search for movies and series
- 📄 Detailed movie and series pages
- 🎞️ Movie trailers
- 📺 Episodes and seasons
- 🖼️ Movie and series posters
- 📱 Responsive design
- ⚡ Dynamic content with Django
- 🗄️ Database integration using Django ORM
- 🎨 Modern and user-friendly interface

Getting Started
Prerequisites

Make sure you have installed:

Python 3.x
pip
Git
1. Clone the repository
git clone https://github.com/salmanasaad1/Movies-Series-website.git
cd Movies-Series-website
2. Create a virtual environment
python -m venv venv
3. Activate the virtual environment
Windows
venv\Scripts\activate
macOS / Linux
source venv/bin/activate
4. Install dependencies
pip install -r requirements.txt
5. Apply migrations
python manage.py migrate
6. Run the development server
python manage.py runserver

Open your browser and visit:

http://127.0.0.1:8000/
